# 🖍️ Listen and Draw (스케치북 에디션)

영어 문장을 듣고, 6개 조가 동시에 그림을 그려서 비교하는 교실 게임입니다.

이제 **화면이 하나(`index.html`)로 합쳐져 있어요.** 접속하면 먼저 **"선생님으로 로그인" / "학생으로 로그인"** 중에서 고르게 됩니다.
- **선생님으로 로그인**: 비밀번호(기본값 `6840`)를 입력해야 들어갈 수 있어요. (TV/프로젝터에 띄우는 화면)
- **학생으로 로그인**: 비밀번호 없이 바로 조 선택 화면으로 들어가요. (조마다 1대씩, 총 6대의 기기에서 접속)

조별 기기는 각자 **제한시간 동안 다른 조의 그림을 볼 수 없고**, 시간이 끝나면 선생님 화면과 모든 조 화면에 한꺼번에 공개됩니다.

---

## 1. Firebase 프로젝트 만들기 (처음 한 번만, 5분)

1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인 → **"프로젝트 추가"**
2. 프로젝트 이름 입력 (예: `listen-and-draw`) → Google 애널리틱스는 꺼도 됩니다 → **"프로젝트 만들기"**
3. 왼쪽 메뉴에서 **빌드 > Realtime Database** 클릭 → **"데이터베이스 만들기"**
   - 위치는 가까운 지역(예: asia-southeast1) 선택
   - 보안 규칙은 **"테스트 모드에서 시작"** 선택 (교실 수업용 1회성 게임이라 테스트 모드로 충분합니다)
4. 왼쪽 위 ⚙️(톱니바퀴) → **프로젝트 설정** → 아래로 스크롤 → **"내 앱"** 에서 **웹 아이콘(`</>`)** 클릭
5. 앱 닉네임 입력 (예: `listen-and-draw-web`) → **"앱 등록"**
6. 화면에 나오는 `firebaseConfig = { apiKey: ..., authDomain: ..., ... }` 값을 전부 복사
7. 이 폴더의 **`firebase-config.js`** 파일을 열어서, 복사한 값을 그대로 붙여넣으세요.
   (`databaseURL` 값이 꼭 들어있어야 해요! Realtime Database를 만든 후에 다시 "내 앱" 설정을 보면 추가되어 있습니다.)

> ⚠️ 테스트 모드는 30일 후 자동으로 잠깁니다. 수업이 끝난 뒤라면 그대로 둬도 되고,
> 계속 쓰실 거면 Firebase 콘솔 > Realtime Database > 규칙 탭에서 기간을 늘려주세요.

## 2. GitHub Pages로 배포하기 (5분)

1. https://github.com 에서 새 저장소(Repository) 생성 (예: `listen-and-draw`), Public으로 설정
2. 이 폴더 안의 **모든 파일**(`index.html`, `*.js`, `*.css`, 이 `README.md` 포함)을
   저장소 **루트(가장 바깥쪽)** 에 직접 업로드하세요.
   - 웹에서 **"Add file" → "Upload files"** 로 업로드할 때, 압축 푼 폴더를 통째로 끌어넣지 말고
     **폴더를 먼저 열어서 안의 파일들만 선택**해서 올려야 해요. (폴더째로 올리면 `index.html`이 한 단계 더 깊은 곳에 들어가서 주소가 안 맞아요!)
3. 저장소 **Settings → Pages** 메뉴로 이동
4. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `root`로 설정 후 저장
5. 1~2분 기다리면 `https://내아이디.github.io/listen-and-draw/` 형태의 주소가 생깁니다

접속 링크는 **딱 하나**예요 (선생님용 / 학생용 구분 없이 같은 링크, 들어가서 역할만 선택하면 돼요):
- `https://내아이디.github.io/listen-and-draw/`

이 링크를 선생님 기기와 학생 기기 6대 모두에 공유하면 됩니다. (QR코드나 단톡방 등으로 공유)
선생님 기기에서는 **"선생님으로 로그인"** 선택 후 비밀번호(`6840`)를, 학생 기기에서는 **"학생으로 로그인"** 을 선택하면 돼요.

## 3. 수업에서 사용하는 방법

1. 선생님 기기와 학생 기기 6대 모두 같은 주소로 접속한 뒤, 각자 역할을 선택합니다.
   - 선생님 기기: **"선생님으로 로그인"** → 비밀번호 `6840` 입력
   - 학생 기기: **"학생으로 로그인"**
   - 선생님 화면을 처음 열면 **문장 20개의 순서가 자동으로 랜덤 셔플**돼요. (새로고침해도 같은 순서 유지, "새 게임 시작" 버튼을 눌러야 다시 섞여요)
2. 학생들은 접속 후 **우리 조(1~6조)를 선택**하고, **조 이름(2~5글자)**을 지어서 입장합니다. (기기에 저장되어 다음에 자동으로 기억해요)
3. 선생님이 **"👁️ 문장 보기"**를 눌러야 선생님 화면에 문장이 보여요. (누르기 전엔 가려져 있어서, 학생들이 화면 너머로 문장을 미리 읽는 걸 막아줘요)
4. 선생님이 **"🔊 문장 듣기"**를 눌러 문장을 들려줍니다.
5. 다 들려준 뒤 **"10초" / "20초" / "30초"** 버튼을 눌러 라운드를 시작합니다. 이 순간부터 조별 화면에 캔버스가 열리고 타이머가 흘러갑니다. (남은 시간 5초부터는 째깍째깍 효과음이 나요!)
6. 제한시간이 끝나면 **선생님 화면과 모든 조 화면에 동시에** (팡파레 효과음과 함께) "정답 그림"(미리 준비된 그림)과 1조~6조 그림이 두 줄로 공개됩니다.
7. 선생님이 각 조 그림 아래 **별 1~3개**를 눌러 점수를 매깁니다. (다시 누르면 취소, 다른 별을 누르면 점수가 바뀌어요) 그 라운드에서 가장 별을 많이 받은 조는 👑 표시됩니다.
   - 점수는 바로 **실시간 점수판**(선생님 화면 오른쪽 + 학생 화면 왼쪽)에 반영돼요.
8. 문장 번호판에서 다음 번호를 눌러 다음 라운드로 넘어갑니다. (다음 라운드로 넘어가면 문장은 다시 가려진 상태로 시작해요)
9. 게임을 처음부터 다시 하고 싶으면 선생님 화면의 **"🔄 새 게임 시작"**을 누르세요. (문장 순서가 다시 섞이고 점수가 0으로 초기화돼요. 조 이름은 그대로 유지돼요)
10. 역할을 잘못 선택했거나 다른 기기로 바꾸고 싶으면 화면 오른쪽 위의 **"🔑 역할 바꾸기"**를 누르면 처음 역할 선택 화면으로 돌아가요.

---

## 4. 문장 / 정답 그림 / 선생님 비밀번호 수정하기

- `sentences.js` 파일을 열면 문장 20개(쉬운 8개+형용사, 기본 난이도 12개)를 자유롭게 바꿀 수 있어요.
- `answer-art.js` 파일에는 각 문장에 맞춰 제가 미리 그려드린 "정답 그림"(SVG)이 들어있어요. 문장 내용을 완전히 바꾸면 그림과 안 맞을 수 있으니, 그럴 땐 다시 요청해주세요!
- 선생님 비밀번호는 `app.js` 맨 위의 `const TEACHER_PASSWORD = '6840';` 값을 바꾸면 돼요.

## 5. 자주 묻는 질문

**Q. 조별 기기 화면에 아무 반응이 없어요.**
A. `firebase-config.js`에 본인의 Firebase 값을 제대로 넣었는지 확인하세요. 브라우저에서 F12(개발자 도구) → Console 탭에 빨간 에러가 있는지 확인하면 원인을 알 수 있어요.

**Q. 조별 기기가 꼭 6대여야 하나요?**
A. 네, 현재는 1~6조로 고정되어 있어요. 조 수를 바꾸고 싶으면 `teacher.js`/`team.js`의 `TEAM_COUNT`, `style.css`의 `.teams-grid`·`.team-picker` 등을 함께 수정해야 해요. (조 수 변경이 필요하면 말씀해 주세요, 바로 고쳐드릴게요!)

**Q. 소리가 안 나와요.**
A. "문장 듣기"는 선생님 기기의 브라우저 음성(TTS)을 사용해요. 째깍 소리·팡파레는 각 기기의 브라우저가 자체적으로 재생해요. 기기의 음량과 브라우저가 소리를 지원하는지(크롬 권장) 확인해 주세요.

**Q. 조 이름을 다른 조가 덮어썼어요.**
A. 조 이름은 기기가 아니라 "조 번호"에 저장돼요. 같은 조 번호를 두 기기에서 동시에 선택하면 나중에 입력한 이름으로 바뀔 수 있으니, 조마다 기기를 하나씩만 쓰도록 안내해주세요.

**Q. 선생님 비밀번호를 잊어버렸어요 / 바꾸고 싶어요.**
A. 기본 비밀번호는 `6840`이에요. 바꾸고 싶으면 `app.js` 파일의 `TEACHER_PASSWORD` 값을 원하는 숫자로 바꾼 뒤 다시 업로드하면 돼요.
